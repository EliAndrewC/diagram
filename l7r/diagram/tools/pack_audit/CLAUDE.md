# `pack_audit/` - the Mode A sheet audit

Split from one `pack_audit.py` by feature 173, as LAYERS emitted bottom-up (every cross-module reference points backwards, so no import cycle). **Load only the file the task calls for**; this index is the map. Run it as `make pack-audit`, which since feature 449 T175 runs the Rust (`l7r-mode-a pack-audit`, `rust/mode_a/src/audit/report.rs`); the package's `__main__.py` was deleted then, and these modules stay for their Python importers (`compound.py`, `tests/test_mode_a_sheets.py`) under the lockstep rule.

## Look here when

|---|---|
| `parse.py` | the SVG reader: the fill/stroke/pattern vocabulary, the four record types (`Rect`, `Label`, `ParsedPlan`), and `parse_svg`, which turns a Mode A sheet into them. Ported to `rust/mode_a/src/parse.rs` (feature 449 T170): an edit here is made there in the same commit |
| `grids.py` | the raster measurements - the occupancy grids and everything derived by counting cells: coverage, perimeter hugging, the largest vacant rectangles, per-region density. Ported to `rust/mode_a/src/grids.rs` (feature 449 T174): an edit here is made there in the same commit |
| `checks.py` | the audits themselves - one function per question asked of a plan, each with its own result record. Add a new check here. Ported to `rust/mode_a/src/audit/checks.rs` and `rust/mode_a/src/audit/checks/walls.rs` (feature 449 T175): an edit here is made there in the same commit |
