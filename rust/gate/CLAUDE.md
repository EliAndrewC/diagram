# `rust/gate/` - the gate's own tools (feature 449 phase 2)

One binary, `l7r-gate`, called from the Makefile through `scripts/gates/l7r-gate.sh`, each subcommand ported from the Python piece it replaces (`specs/449-rust-codebase/tasks.md`, T062-T069). `make static` and `make rust-test` check it beside the other crates.

**The gate is a binary over crates** (T92, the GM 2026-11-11: an edit recompiles one crate and what depends on it, not 74,199 lines). `rust/gate` itself is the binary, `l7r_gate`: `src/lib.rs` dispatches each subcommand, `src/main.rs` prints the reply. The work is in `crates/<dir>/`, package `l7r_gate_<dir>`, each keeping the module paths it had in the one crate (`crate::record::owed`, `crate::checks::py_repr`): a crate's `lib.rs` re-exports what it reads of the crates below it under those names, so a moved file's paths still resolve. Each crate owes 100% of its own lines by its own tests (`make rust-test CRATE=rust/gate/crates/<dir>`), and its test helpers come from `core`'s `testkit` feature. A gate crate names another by `path` and an outside crate only as `{ workspace = true }` (`rust/Cargo.toml`), so one crate's build never rebuilds another's dependencies. A crate's `[dev-dependencies]` name `testkit` on every crate of its build that has the feature, itself included (`path = "."`), so a library is compiled with one feature set in every test and coverage build (451 T325); `checks`' test `guard_deps/feature_sets.rs` fails with the line to add. A crate that names itself is linted a third time, `cargo clippy --lib`, which reads no dev-dependency, so its lines compiled only with the feature off are still linted (`rustc.rs`, `names_itself`).

**The checks reuse a crate's last green result** (T93, the GM 2026-11-11). `make rust-test`, `make static` and `make counters-inert` run a crate's test, cover, lint or dead again only when its key moves: its sources, the crates it builds from by path, the workspace's manifests, and what its tests read of the tree at run time, which its `Cargo.toml` declares (`[package.metadata.l7r] reads = ["scripts/", ...]`, `"."` the whole tree). A test run whose key moved builds the test binary first and runs nothing when that binary already passed (`test` and `test-counters` share it); the owed crates' binaries then run directly, several crates at once (`rustc/side.rs`, T160). A crate whose sources name the tree (`CARGO_MANIFEST_DIR`, `top()`, `toplevel()`) with nothing declared is refused: declare what its tests read. Every crate fresh is `FRESH=1 REASON="<two words or more>"`, recorded, or `make done FULL=1`. The kept results live in the clone's `.git/rust-checks/`.
