# `rust/guard/` - the guards on Claude Code's tool calls (feature 449 phase 1)

One binary, `l7r-guard`, replaces the repository's 44 shell guards one task at a time (`specs/449-rust-codebase/tasks.md`,
T006-T049): Claude Code calls it once a hook event through `scripts/hooks/l7r-guard.sh` (T004), it reads the input once and runs
every guard's check in a fixed order, and merges their answers by `specs/449-rust-codebase/contracts/guard-protocol.md`.

| file | look here when |
|---|---|
| `src/lib.rs` | the crate's surface: `guards()` in their fixed order, `cli` - the command line (`<event>`, `--only`, `--idle-tests`, `--agent-stall`, `--stall-watchdog`, `--finished-run`, `--self-check`, `--version`) |
| `src/protocol.rs` | the hook protocol: the event, the answers, the merge (`run`); its tests in `src/protocol/tests.rs` |
| `src/shared/` | what every guard reads (T003): `shape` (heredoc and quote stripping), `escape` (the tokens' two-word reasons), `session` (the facts read once a process - the mirror, the clone, the transcript, the GM's messages - each read counted), `transcript` (`gm_messages`), `log` (the guard log, `guardlog.sh`'s format), `tool` (asking a tool the guards consult, T006 decision (a)), `sha256`, `make` (the make targets a command invokes, `hm_make.py`'s parts T007 reads), `state` (a session's state file, an input field), `wait` (the shapes of a wait, `hm_shape.py`'s wait half), `tree` (where a command's writes land, `hm_tree.py`), `sha1` |
| `src/guards.rs`, `src/guards/` | the guards, one module each in their fixed order: `pair_hooks` (T006) - the gate and its review together, its state (`state.rs`) and its review checks (`review.rs`); `gate_hooks` (T007) - no `-k` subset as the only run before the gate, quick and done combined; `measure_hooks` (T008) - the expensive measurement batched; `no_poll_hooks` (T009) - no busy-wait, the file wait made safe; `main_tree_hooks` (T010) - a write landing in the mirror moved to the clone; `event_log_hooks` (T012) - a line of the feature's event log on every event; `clone_sync_hooks` (T013) - the session's clone synced on a prompt, an edit routed to its own clone on a current base (`resolve` alone stays in `scripts/hooks/clone-sync-hooks.sh` until T051); `idle_tests_hooks` (T014) - a Stop arms the idle run, disabled by the GM's switch, a prompt disarms it; `agent_stall_hooks` (T015) - a stalled subagent reported at the next prompt; `stall_watchdog_hooks` (T016) - any prompt keeps the loop outside every session running; `finished_run_hooks` (T017) - a finished run surfaced, a turn not closed over a run nothing will wake, `runs.rs` the `/proc` walks; `engine_freeze_hooks` (T018) - no engine edit under a running review or roll; `gm_tree_hooks` (T019) - no write into gm-assistant's main tree; `batching_hooks` (T020) - a run of single bare reads refused; `no_branch_hooks` (T021) - no git branch created; `discard_hooks` (T022) - no checkout or restore that throws away uncommitted work; `conflict_marker_hooks` (T023) - no staging of an unresolved merge conflict; `gate_write_hooks` (T024) - no write the gate would see while it runs; `feature_approval_hooks` (T025) - no new feature without the GM's quoted approval; `budget_change_hooks` (T026) - a work budget changes only with the GM's own words; `ledger_hooks` (T027) - no commit of a ledger row short of a cell; `archive_first_hooks` (T030) - the archive before the web; `claims_file_hooks` (T031) - the claims sheet only through its tool; `readme_hooks` (T032) - no README; `download_copy_hooks` (T033) - not the GM's download copy; `phase_source_hooks` (T046) - a stage rebuilt from its derivation, not its old code; `new_file_hooks` (T047) - a new prefixed file takes a reserved prefix; `blocked_fetch_hooks` (T039) - no fetch of a blocked domain, every other fetch an attempt on the log; `set_down_hooks` (T049) - a turn ends with a started feature's tasks open only once it is set down; `repo_safety_hooks` (T034) - no force push, no history rewrite, no git write at the mount; `agent_model_hooks` (T041) - an ad-hoc agent names its model; `wakeup_hooks` (T038) - a timed wakeup cannot outlive its purpose; `agent_prefix_hooks` (T042) - a prompt repeats no large block, a wave goes through check-wave; `workflow_hooks` (T040) - a Workflow is held to the guards its agents would meet; `source_block_hooks` (T037) - the GM's own writing is not editable; `house_style_hooks` (T036) - hyphens and American spellings, corrected; `shell_check_hooks` (T035, last) - a command that cannot work is refused before it runs |
| `src/main.rs` | the binary: prints `cli`'s reply and exits with its code |

`make rust-test`, `make static` check it beside `rust/phases` (the workspace, `rust/Cargo.toml`).

A guard's suite replays through its link `tests/hooks/<guard>.sh` -> `tests/hooks/guard-shim.sh`, which runs
`l7r-guard --only <guard> <event>`; `make hooks-test` finds a ported guard by that link.
