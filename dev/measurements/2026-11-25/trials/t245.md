# T245 worktree frictions (2026-11-25)
- `make guard-edit FILE=` on a not-yet-existing tests.rs path exits 2 (Makefile:411); a new guard source file (evict.rs, low.rs, audit.rs) needs guard-edit before its first Write, a new tests.rs does not.
- A Python heredoc script that edits the Makefile is refused as "a guard file written from a shell command", even with the escape comment on the run that follows: the heredoc write itself is the refused call, so the script never exists; use make guard-edit then the Edit tool.
- `make decide` prints only the MODE 4 dispatch line on success; the recording command is in the bundle MANIFEST.
