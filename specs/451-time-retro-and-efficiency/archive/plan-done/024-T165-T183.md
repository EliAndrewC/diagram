**THE PRICE OF A REVIEW, measured 2026-11-23.** A review costs R = 14.4k tokens: every `message-check` dispatch of the three rounds read 14k tokens in (6k to 10k of it cached) and wrote 0.3k to 0.7k out (`make review-cost`, e.g. ab9b70f54e3ec0099, a92df90484ef842d4, a91ac500286d36459). A token is rho = 2.2 characters of a guard message: the median over 703 guard refusals the builders read, each the rise in the next model call's context (input, cache read and cache creation) less the call's own output, the quartiles 2.12 and 2.20 (`/tmp/t177/scripts/rho.py`, `GUARD=1`, over the 1,658 subagent transcripts). So one review is R x rho = 31,680 characters, and a family of k BASELINE keys, one review a key, costs k x 31,680 a round. THE CONVENTIONS: both sides count a token once as it enters a context (T170's measure); the review's cached input counts in full; a session's re-reads of a message still in its context are not counted, which would raise every saving; the reviews run on Sonnet and the sessions on Opus, priced alike here.
