# The GM's request, verbatim (2026-08-28, session "Diagram research")

> This project has a lot of rules around how we perform research and then how we document that research and the files in which the research is documented separate from the actual items, which appear on maps and so forth. However, a rule which was added to our speckit constitution and our project guidelines after we had already done a lot of research was that all research should have citations. And I think that a lot of our past research does not. I would like you, therefore, to essentially find all of the research that we have done in the diagram skill, which does not cite sources. and then redo those research passes. You don't need to rewrite those findings if they are the same, though if your research adds to them or finds things which do usefully supplement them, then that is fine. You can make those additions. The main thing that we want is to make sure that there are citations for all of the things that we have found. And then, of course, if it turns out based on this kind of research review that any of our findings are wrong, like if you find new sources that contradict what was there or if the previous summaries that we had found did not accurately summarize what was true, then it might be that we need to make some changes. In these cases, you should update the research findings with the new citations, but do not make any actual changes to the maps or the map generation. if you find anything like this, then we should talk about what to do next and whether we want to document this as future work. This seems like a large undertaking worthy of its own spec kit feature, so please proceed with that. Thanks.
