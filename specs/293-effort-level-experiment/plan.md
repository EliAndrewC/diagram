# Implementation Plan: The effort-level experiment (a pilot)

**Branch**: none (`main`; `SPECIFY_FEATURE=293-effort-level-experiment`) | **Date**: 2026-09-29 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/293-effort-level-experiment/spec.md` (accepted, spec-fidelity FAITHFUL round 2)

## Summary

Four headless runs - task R (the Ubame servants' quarters question) and task I (the hamlet burial-ground footpath), each at
`medium` and at `xhigh` - measured, graded blind and reported under the spec's FR-011 rule. The tooling is small and built
on what exists:

- **The launcher** `make effort-run` makes a fresh clone at the recorded start commit under a neutral run id and starts the
  run detached. Task R runs through the existing page-session runner (write brief, then check-and-apply brief), which gains an
  `EFFORT=` argument passed straight through to `claude -p --effort`; task I runs as one full headless session started the
  same way (same session-id choice, same detachment, same `result.json`), but with the project's full instructions and tools,
  because engine work is not a page session.
- **The measurement** `make effort-measure RUN=<id>` reads every transcript of the run (each session's and each subagent's),
  folding usage per message id the way `_agent_census.py` already does (the per-field maximum; research R3 of this plan), and
  reads the rework signals from the host guard log (filtered by the run's session ids), the run clone's git log, the review
  verdicts in the subagent transcripts and the `make` results in the session transcripts.
- **The blinding** `make effort-blind TASK=R|I` exports each run's output from its clone (the research fragments and their
  notes; the engine diff with the moved maps' PNGs and notes), strips arm-identifying text, labels A/B from a seed, and writes
  the key outside anything the grader is given.
- **The grader** is a new defined agent, `effort-grader` (Opus, `effort: high`, `omitClaudeMd: true`), reading a bundle made
  outside the repository, as every check here does.
- **Rubrics and prompts** are committed before the first run; the report is `report.md` in this directory.

Writing the plan and the tasks is this session's; building the tooling and running the four runs is the implementing session's.

## Technical Context

**Language/Version**: Python 3 (scripts under `scripts/`, tests under `.claude/skills/diagram/tests/tooling/`), bash for the
two thin entry points; Makefile targets in `.claude/skills/diagram/Makefile`.

**Primary Dependencies**: the Claude Code CLI (`claude -p`, `--effort`, `--session-id`, `-n`); nothing new to install.

**Storage**: per-run records in this feature directory (`runs/<run-id>.json`, `measurements/<run-id>.json`, `grades/`), the
sealed key under `.git/effort-keys/` of the SESSION's clone (untracked, never bundled), and committed to the feature directory
only after grading.

**Testing**: pytest through `make test-file` / `make quick`; the launcher, measurement and blinding logic tested on saved
fixture transcripts and a throwaway git repository - never a live `claude` call (a fake `claude` on `PATH` records the argv).

**Target Platform**: the diagram container (Linux), sessions on the host-mounted `~/.claude`.

**Project Type**: repository tooling plus a procedure.

**Performance Goals**: none for the tooling; the runs' own cost is the thing measured.

**Constraints**: the container memory cap (runs strictly sequential, a check for no other live run before a launch - R5); no
engine code in the tooling (the tooling lands on the DIRECT route; task I's winner lands GATED on its own); the prompts
byte-identical across arms.

**Scale/Scope**: four runs, two graded pairs, one report.

**Single-artifact target**: none for the tooling (no generator change). Task I's runs pick their own reference map as the
project's rules require; the prompt names Inashiro as the reference hamlet (the project's standing reference).

**Every step is two steps.** Not applicable to the tooling; task I's prompt requires it of the run (reference hamlet first,
then the pool).
