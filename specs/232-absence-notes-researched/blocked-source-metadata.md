# Bibliographic identity of the nineteen blocked or unreadable sources

Metadata only. Nothing here was read for content and nothing is quoted from any of these documents; the
task was to establish who wrote what, where it was published, and whether a person can get at it.

Resolved 2026-09-12 against Crossref, OpenAlex, Unpaywall, Semantic Scholar, DOAJ and OpenLibrary, plus
direct HTTP probes with a browser user agent. "What blocks it" records the observed behavior, which is
usually bot filtering rather than a paywall: several of these are open-access by license and still
return 403 to an automated client.
