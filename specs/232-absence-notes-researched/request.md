## The one reading this feature takes, stated so it can be challenged

**"Epson's notes" is dictation for "absence notes".** The argument is not phonetic resemblance. It is
that the GM's message is a three-paragraph reply to the three sections of feature 229's closing report
([`../229-rule-files-into-research/closing-report.md`](../229-rule-files-into-research/closing-report.md)),
in order:

| the GM's paragraph | the report section it answers |
|---|---|
| 1. "I authorize you to fix the research readme" | section 1, "The README correction, offered and NOT applied" |
| 2. "files such as buildings dot md Should remain" | section 2, "The Mode A question" - does a mode a person draws by hand keep one operative document? |
| 3. "run down all of the Epson's notes ... find sources and citations for those things" | section 3, "What the record still does not know", whose headline is that 108 of the 176 new footnotes are ABSENCE notes |

No competing reading survives that correspondence. The phonetics, and the fact that nothing in this
project is named Epson, are corroboration rather than the argument.

Paragraphs 1 and 2 were acted on the same day: the README was corrected under the authorization in
sentence one, and Mode A's `buildings.md` stays operational, which is now written into the README itself
in the GM's own words. This feature is paragraph 3.

**What that section named which this feature does NOT take.** It gave TWO numbers - 113 claims labeled a
guess, and 108 footnotes that are absence notes. The GM's words are "all of the [absence] notes", so this
feature is the second number. The guesses that carry no absence footnote of their own are recorded as out
of scope in `spec.md`, with the reason, rather than being silently included or silently dropped.
