• aze-jawiki - 「Those that also serve as a path for going round the paddy fields are called azemichi, or nawate.」 (translated from the Japanese by this project; original: 「水田を回る際の道としての役割も持っているもののことを、畦道（あぜみち）、畷（なわて、縄手とも）という。」) (the path on the baulk; 「never crosses row crops」 and 「along the edge of the hem」 are this page's, the agricultural headland being cropped ground)
  • aze-jawiki - 「The aze, in rice farming, is made by heaping up mud from inside the paddy on the boundary between one paddy and the next, so that the water does not leak out.」 (translated from the Japanese by this project; original: 「畦（あぜ）は、稲作農業において、水田と水田の境に水田の中の泥土を盛って、水が外に漏れないようにしたものである。」) (with the note above, which calls the aze that serves as a path an azemichi: the path is on the plot boundary; that the drawn lane may touch a plot's edge is this page's rule for the map)
  • kotobank-azemichi - 「A narrow path between one field and another.」 (translated from the Japanese by this project; original: 「田と田の間の細い道。」)
