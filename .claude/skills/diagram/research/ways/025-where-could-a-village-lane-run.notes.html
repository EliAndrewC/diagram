  • aze-jawiki - 「The aze, in rice farming, is made by heaping up mud from inside the paddy on the boundary between one paddy and the next, so that the water does not leak out.」 (translated; ) (with the note above, which calls the aze that serves as a path an azemichi: the path is on the plot boundary; that the drawn lane may touch a plot's edge is this page's rule for the map)
