mapbox-variable-label-placement

Mapbox, Mapbox GL JS examples, "Variable label placement" (https://docs.mapbox.com/mapbox-gl-js/example/variable-label-placement/)

What it is: A worked example in the documentation of Mapbox GL JS, a widely used library for web maps, showing how a label may take the first of several anchor positions around its point that fits, in an order the map's author lists.

Why it applies, and its limits: It shows a major mapping library's own example listing the four adjacent positions - top, bottom, left, right - with no corners, the same order these maps try first. It is one example's settings, not a stated default or a cartographic guideline, and it gives no reason for the order.

Used for: an order that tries the four adjacent positions and no corners (presentation)
